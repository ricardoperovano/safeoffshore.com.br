# Safe Offshore - Versão 2 (ShipMarine Inspired)

## 📋 Visão Geral

Esta é a segunda versão do site Safe Offshore, inspirada no design corporativo e profissional do ShipMarine. A nova versão mantém todo o conteúdo original, mas com um visual mais empresarial e moderno.

## 🎨 Principais Mudanças de Design

### Paleta de Cores
- **Navy Blue Profissional** (#1a2e4a) - Cor primária
- **Azul Corporativo** (#2c5f8d) - Cor secundária
- **Laranja Destaque** (#ff6b35) - Acentos
- **Cinza Escuro** (#32373c) - Botões principais

### Estilo Visual
- ✅ Design mais corporativo e profissional
- ✅ Botões retangulares com cantos levemente arredondados (4px)
- ✅ Navegação com uppercase e underline animado
- ✅ Cards com borda lateral colorida
- ✅ Ícones em fundos quadrados
- ✅ Sombras mais suaves e discretas
- ✅ Animações mais sutis

### Tipografia
- Headlines em navy blue
- Melhor hierarquia visual
- Espaçamento otimizado
- Fonte corporativa

## 🔧 Manutenção

Para atualizar a Versão 2:
1. Edite o arquivo `css/safeoffshore-style.css`
2. As mudanças serão refletidas em todas as páginas `-v2.html`

Para reverter para a versão original:
1. Basta usar os arquivos sem o sufixo `-v2`
